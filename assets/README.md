# 设定资产

本目录保存可直接用于角色与美术生产的设定资料。资产按设定门类归档，每个门类分别保存说明文档、参考图和正式设定图。

## 目录

```text
assets/
└── 服饰/
    ├── 服饰设定.md
    ├── 参考/
    │   ├── 中式长裙-帽饰皮鞋搭配参考.jpg
    │   ├── 明制汉服-深蓝比甲结构参考.jpg
    │   └── 维多利亚服饰-插画氛围参考.jpg
    └── 三视图/
        └── 中式维多利亚女装-标准三视图.png
```

## 命名规则

- 参考图使用“内容-参考用途”命名，不保留下载平台生成的无意义文件名。
- 正式设定图使用“对象-图面类型”命名。
- 同一对象需要迭代时，在文件名末尾增加 `-v2`、`-v3`，不覆盖已经用于文档的版本。
