# 《无事发生》Nothing Happens 设计文档总览

> 一款以“害怕落后”为主题、用提案构筑与议会博弈改造自走棋循环的单人策略游戏。

## 游戏概述

玩家扮演蓬莱联合政府最后的驻岁执政者。每月，种族政党与利益集团会送来提案，并以各自掌握的消息说明危机为何迫近。玩家需要判断消息中的事实与偏见，整理、谈判和合并提案，再决定是否把草案送入议会。

通过的提案不会立刻改变市场，而会逐步被消化。干预可以处理眼前的局部问题，也会让各方更相信全面危机确实存在，从而催生更多警告、提案与调控。玩家也可以承受这种压力，停止追赶，观察危机预期自行消退。

## 核心体验

- **辨别消息**：来访者能较早提供判断，但其说法受到身份、关系和利益影响；报纸更可靠，却只报道已经迫近的局部事件。
- **整理提案**：系统自动送来的卡牌往往满足一方诉求，同时把代价转移给另一项公共指标或另一群人。
- **观察消化**：提案与政策的影响逐步形成，从法案中移除后也会逐步退出，玩家需要判断变化趋势而非只看最终结果。
- **争取议会**：种族偏好、提案来源、利益集团、个人关系和贿赂共同决定法案能否取得足够支持。
- **抵抗紧迫感**：持续干预会累积调控压力；停手越久，各方越焦急，送来的方案也越诱人。
- **允许无事发生**：唯一结局并非彻底消灭滞后，而是容忍滞后，不再用干预证明危机存在。

## 术语

- **蓬莱**：郑和船队为海上异族所居之岛起的汉文名称，也是各族联合政府的通称。
- **种族政党**：以共同生活方式和政治诉求组织起来的议会阵营。
- **未然**：由生灵对尚未发生之事的焦虑凝成的能源，可用于供热、照明、机械动力和远距通信。
- **提案卡牌**：构筑法案的基本单位，包含来源、影响方向、消化过程与政治含义。
- **现行法案**：已经由议会通过、正在市场中逐步产生影响的提案组合。
- **政策**：局外解锁、局内主动启用，并在满足条件后逐步执行的组合规则。
- **消化**：提案或政策的影响逐步形成或退出的过程。
- **公共指标**：描述蓬莱财政、市场、劳动、生产和对明关系变化的账簿项目，不代表统一的好坏。
- **崩溃度**：各族相信全面经济崩溃即将发生的集体预期，不是客观经济健康值。
- **行身**：一具已经点醒的偃偶身体；在户籍制度中是公民，在商业制度中同时是可交易的商品。
- **事件**：真实但局部的市场波动，也是玩家需要提前准备的下一轮挑战。
- **任期**：一轮从空法案开始的游玩。普通失败只结束本任，不是故事结局。
