# 《无事发生》Nothing Happens 设计文档总览

> 一款以“害怕落后”为主题、用提案构筑与议会博弈改造自走棋循环的单人策略游戏。

## 游戏概述

玩家扮演蓬莱联合政府最后的驻岁执政者。每月，各族会以年度期望说明自己认为蓬莱落后在哪里，利益集团则送来带有副作用的普通提案。玩家需要判断哪些种族事件更可能形成、辨别消息中的事实与偏见，整理、谈判和合成提案，再决定是否把草案送入议会。

通过的提案不会立刻改变市场：新法逐步形成，旧法逐步退出，最慢提案决定整份法案的反应时间。事件处理结果会改变各族对议会的信任，次年重组种族席位；本年首次通过并新加入现行法案的提案来自哪些集团，则会重新分配议员的集团影响关系。玩家随后只能修订一次《蓬莱约法》，再面对继续提高的时代期望。干预可以处理眼前问题，也会催生更多警告与调控；若玩家从本任开始便始终不批准法案、不启用政策也不修订约法，则可以承受整轮压力，观察危机预期自行消退。

## 核心体验

- **预测事件**：年度期望与实际状态的差距让玩家模糊判断未来问题；来访者能补充早期线索，但会受到身份、关系和利益影响。
- **整理提案**：三张同集团、同类型提案可以合成；数值从母卡间随机继承或生成，玩家只能固定比例减轻一项负面词条，不能直接删除代价。
- **观察消化**：新旧法影响在市场中重叠，不同速度与轻微波动会改变政策连锁顺序，玩家需要判断实际路径而非只看终点。
- **经营议会**：事件结果重组种族行；本年首次通过并新加入法案的提案来源份额重排集团影响，形成“影响席位—提案通过—影响扩张”的正反馈。
- **修订约法**：每年一次、不可撤回；五条种族轴沿 20%、50%、90% 推进，监管轴则从哲人王单向走到透明政府。
- **抵抗紧迫感**：持续干预会累积调控压力；停手越久，各方越焦急，送来的方案也越诱人。
- **允许无事发生**：唯一结局并非彻底消灭滞后，而是容忍滞后，不再用干预证明危机存在。

## 术语

- **蓬莱**：郑和船队为海上异族所居之岛起的汉文名称，也是各族联合政府的通称。
- **会同**：由郑和首次登陆之地发展而成，后来成为联合政府诞生地、议会所在地和蓬莱当代首都。
- **永乐港**：位于会同城内、蓬莱唯一能够稳定承担远洋贸易的港区，是大明进入蓬莱的门户；不要与城市会同混称。
- **永乐轮运局**：围绕永乐港形成的官督商办运输集团，是组织，不是城市或港区。
- **种族政党**：以共同生活方式和政治诉求组织起来的议会阵营；通过年度期望和约法表达长期诉求，不提供普通提案。
- **利益集团影响**：每名议员本年实际听从的一个组织。常设产业集团通常跨越种族，约法也能生成只负责一地一席的地方集团；议会关系会根据上一年首次通过并新加入法案的集团提案来源份额重新随机。
- **未然**：蓬莱原生诸族因焦虑尚未发生之事而产生的奇幻能源；人类无法产生，只能收集、储运和使用。
- **提案卡牌**：构筑法案的基本单位，包含来源、影响方向、消化过程与政治含义。
- **现行法案**：已经由议会通过、正在市场中逐步产生影响的提案组合。
- **政策**：由本任约法节点或节点组合解锁、由玩家主动启用，并在满足条件后逐步执行的组合规则。
- **消化**：提案或政策的影响逐步形成或退出的过程。
- **年度期望**：某族当年希望达到的经济状态；与实际状态的差距用于路由该族事件。人类额外要求扩大永乐轮运局影响，而非增加本族席位。
- **政治信任**：某族是否相信联合政府能解决本族问题；由事件结果改变，并在次年转化为种族行席数。
- **《蓬莱约法》**：每年只能修订一次、且无法撤回的高层制度文件；五条种族轴以 20% 为历史常态层、50% 为制度重组层、90% 为互斥终局层。驻岁监管不读席位比例，只把献金发现率从 0% 依次提高到 20%、50% 和 100%。
- **公共指标**：描述蓬莱财政、市场、劳动、生产和对明关系变化的账簿项目，不代表统一的好坏。
- **崩溃度**：各族相信全面经济崩溃即将发生的集体预期，不是客观经济健康值。
- **行身**：一具已经点醒的偃偶身体；在户籍制度中是公民，在商业制度中同时是可交易的商品。
- **事件**：由各族年度期望与实际状态差距推动形成的政治问题，也是玩家需要提前准备的下一轮挑战。
- **任期**：一轮从空法案、约法历史常态和新政治局面开始的游玩。普通失败只结束本任，不是故事结局。
