# 《无事发生》Nothing Happens 设计文档总览

> 一款以“害怕落后”为主题、用提案构筑与议会博弈改造自走棋循环的单人策略游戏。

## 游戏概述

玩家扮演蓬莱联合政府最后的驻岁执政者。每月，各族公开自己对税课、物价、工钱、用工与商贸的年度期望，利益集团则送来以负面经济代价换取政治支持的普通提案。玩家整理、谈判和合成提案，把不同集团的卡牌与落差政策构筑成法案，再决定是否送入议会。

每份新法正式接替现行法案时，以当时实际市场为起点；提案决定充分消化后的纯提案目标，却以缓慢、随机且总体顺势的路径形成。政策是每份法案重新授予的一次性授权：当前指标关系满足条件便立即完整触发，并能继续引发同批或下一批政策；相同法案也会重新授权，其中政策通过消耗、转移或放大指标落差形成不同结果。事件从 50% 基础强度萌芽，未控制就向 100% 恶化并登报；议席越多通常只让玩家越可能提前获得本族事件的真实情报。事件结果会改变各族对议会的信任，次年重组种族席位；本年提案来源则重排议员受到的集团影响。若玩家从本任开始始终不批准法案、不奏请也不修订约法，则可以承受整轮压力，观察危机预期自行消退。

## 核心体验

- **预防事件**：所有种族年度期望始终公开；具体事件情报一旦获得必然真实，较多议席带来的是更早准备时间而非数值减免。
- **整理提案**：每个集团只有一种固定负面模板；任意三张同集团牌可以合成，保留早期低负面底子并继承、升级后期额外牌的单一正面词条。
- **构筑路径**：提案用固定数值缓慢随机消化，政策读取指标关系与落差并一次性瞬间触发；纯提案目标与总体趋势可判断，真正决定政策链的是中间路径和触发顺序。
- **经营议会**：事件结果重组种族行；本年各份通过法案中获得新授权的提案来源份额重排集团影响，形成“影响席位—提案通过—影响扩张”的正反馈。
- **软性反雪球**：集团影响力越低，普通发牌权重和额外赠牌概率越高；两者均有上下限，不会无限放大。
- **修订约法**：每年一次；五条种族轴从中央常制向两侧推进且不可撤回，监管轴每任固定从哲人王开始，可无条件改为有限监管、言论自由、透明政府或锦衣卫。
- **抵抗紧迫感**：持续干预会累积调控压力；停手越久，各方话术越焦急，早期低负面底子与后期高附益之间的合成诱惑也越醒目。
- **允许无事发生**：唯一结局并非彻底消灭滞后，而是容忍滞后，不再用干预证明危机存在。

## 术语

- **蓬莱**：郑和船队为海上异族所居之岛起的汉文名称，也是各族联合政府的通称。
- **会同**：由郑和首次登陆之地发展而成，后来成为联合政府诞生地、议会所在地和蓬莱当代首都。
- **永乐港**：位于会同城内、蓬莱唯一能够稳定承担远洋贸易的港区，是大明进入蓬莱的门户；不要与城市会同混称。
- **永乐轮运局**：围绕永乐港形成的官督商办运输集团，是组织，不是城市或港区。
- **种族政党**：以共同生活方式和政治诉求组织起来的议会阵营；通过年度期望和约法表达长期诉求，不提供普通提案。
- **利益集团影响**：每名议员本年实际听从的一个组织。常设产业集团通常跨越种族，约法也能生成只负责一地一席的地方集团；议会关系会根据上一年通过法案的集团提案来源份额重新随机，低影响力集团则获得更高的有界发牌权重与额外来访概率。
- **未然**：除偃偶外的蓬莱原生种族因焦虑尚未发生之事而产生的奇幻能源，也是幻想种族异能与蓬莱工业的共同能源；散布全岛的古老听弦塔使蓬莱成为唯一能够稳定收集和利用未然的地方。
- **提案卡牌**：构筑法案的基本单位，按来源集团的唯一模板提供固定负面经济值、缓慢随机消化与政治支持。
- **正面词条**：集团主动来访额外牌携带的单一固定收益，可在同集团三合一中继承和升级。
- **现行法案**：已经正式接替旧法的提案与政策组合；以生效时的实际经济为起点，另行计算纯提案目标。
- **政策**：由本任约法节点或节点组合解锁、由每份生效法案重新授予的一次性授权；当前指标关系满足条件便立即触发，效果主要把指标落差转化为其它指标变化。
- **消化**：提案影响按各自速度向固定绝对目标随机推进的过程；政策不消化。
- **年度期望**：某族当年希望达到的经济状态；与实际状态的差距用于路由该族事件。人类额外要求扩大永乐轮运局影响，而非增加本族席位。
- **政治信任**：某族是否相信联合政府能解决本族问题；由事件结果改变，并在次年转化为种族行席数。
- **《蓬莱约法》**：每年只能修订一次的高层制度文件；五条种族轴以中央常制为起点，按节点明示的 0%、50% 或 90% 门槛向左右推进，五个 90% 终局互斥。驻岁监管每任固定为哲人王，不参与随机，也不读议席、前置或局外解锁条件；玩家可直接改为任一监管节点。
- **公共指标**：全游戏统一使用税课、物价、工钱、用工、商贸五项；工钱涵盖工时与劳动待遇，不再增加种族专属经济指标。
- **崩溃度**：各族相信全面经济崩溃即将发生的集体预期，不是客观经济健康值。
- **行身**：一具已经点醒的偃偶身体；在户籍制度中是公民，在商业制度中同时是可交易的商品。
- **事件**：由各族年度期望与实际状态差距推动形成、从 50% 基础强度开始变化的政治问题；有效强度达到 100% 才登报，80% 满足率只能暂停，100% 满足率才开始缓解。锦衣卫会使全部事件的有效强度增加 20 个百分点。
- **任期**：一轮从空法案、六项约法常制和新政治局面开始的游玩。普通失败只结束本任，不是故事结局。
